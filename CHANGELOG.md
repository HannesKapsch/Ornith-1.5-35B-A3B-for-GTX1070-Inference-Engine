# Changelog

## 1.0.0

First public release.

- Ornith-1.5-35B-A3B (NVFP4) on one GTX 1070 (8 GB), Windows, at about 25–30 tokens/s
- OpenAI, Anthropic and Ollama compatible APIs with streaming, tool calls, thinking, image input and JSON mode
- Prefix cache: exact checkpoints, RAM parking, compressed disk snapshots
- Quality modes: exact, fast and turbo
- Settings panel in the browser
- Installer with its own Python, resumable download, progress output, status and uninstaller
- `--bench` for comparable speed numbers and `--fake` for development without a GPU
