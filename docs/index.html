Run a 35B LLM on a GTX 1070 (8 GB): Ornith-1.5-35B-A3B Inference Engine

A 35B-parameter mixture-of-experts model on a single 8 GB GTX 1070, at about 25–30 tokens per second.

View on GitHubDocumentation

Custom CUDA inference engine that runs Ornith-1.5-35B-A3B (35B MoE, NVFP4) on one GTX 1070 with 8 GB VRAM on Windows at 25-30 tok/s. Expert streaming, fused NVFP4 kernels, prefix cache, OpenAI-, Anthropic- and Ollama-compatible API.

Features

Bigger than the card

22 GB of weights on an 8 GB GPU: hot experts stay in VRAM, more in pinned RAM read over PCIe, the rest streams from the SSD with a predictor that prefetches the next layer.

Fused NVFP4 kernels

4-bit weights are decoded in registers inside the matrix-vector kernels, built at run time with CuPy/NVRTC for the GTX 1070 (no tensor cores, no FP4).

Drop-in API

OpenAI-, Anthropic- and Ollama-compatible server with streaming, tool calls, thinking and image input. Works with Claude Code, Cline, Continue, Open WebUI and aider.

Long contexts

Compact int8 KV cache plus linear-attention layers allow up to 184k tokens of context.

Prefix cache

Checkpoints, conversation switching and disk snapshots: resuming a 150k-token conversation takes seconds, not 23 minutes.

Quality modes

exact (lossless), fast (+26 % speed) and turbo (+42 % speed) with measured perplexity cost.

Install

git clone https://github.com/Kessler833/Ornith-1.5-35B-A3B-for-GTX1070-Inference-Engine.git
cd Ornith-1.5-35B-A3B-for-GTX1070-Inference-Engine
install.bat --dir C:\ornith

Full instructions, requirements and troubleshooting are in the README on GitHub.
